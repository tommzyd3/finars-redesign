# FIN ARS – Modern Website Redesign

Sodobni redesign spletišča [www.finars.si](https://www.finars.si) v Apple-stilu.

## Značilnosti

- Čisto belo ozadje z nežno menjajočimi arhitekturnimi fotografijami (Unsplash)
- Responsive dizajn (desktop + mobile)
- Podstrani za vsak projekt
- Lightbox – slike se povečajo ob kliku
- Filter projektov po letih
- Originalne slike iz finars.si

## Struktura

- `index.html` – Domov
- `projekti.html` – Seznam vseh projektov
- `o-nas.html` – O podjetju
- `kontakt.html` – Kontakt
- `projekti/` – Posamezne projektne podstrani

## Uporaba

Odprite `index.html` v brskalniku ali naložite na strežnik / GitHub Pages.

```bash
# GitHub Pages
# Settings → Pages → Source: main branch
```
